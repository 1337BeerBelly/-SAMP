# open.mp DM/TDM

Стартовый игровой режим для **open.mp** на Pawn. В репозитории доступны `.pwn` и собранный `.amx` для прямого скачивания. GitHub Actions дополнительно пересобирает режим и публикует оба файла одним артефактом.

## Что уже есть

- режим Team Deathmatch по умолчанию с автоматическим распределением игроков между RED и BLUE;
- возможность выбрать обычный Deathmatch (каждый сам за себя) через `DEFAULT_MATCH_MODE`;
- простая тестовая арена и случайная точка появления для команды;
- стартовый набор оружия, здоровье и броня;
- счёт команд, лимит в 30 убийств и раунд до 15 минут;
- команды `/help` и `/stats`;
- `config.json` для open.mp без включённого RCON.

Координаты арены, оружие и лимиты — базовые настройки для прототипа; их можно заменить под задумку сервера. Системные сообщения в первой сборке на английском; русскую локализацию добавим отдельно с учётом кодировки клиента.

Чтобы собирать обычный FFA Deathmatch вместо TDM, поменяйте в `gamemodes/dm_tdm.pwn`:

```pawn
#define DEFAULT_MATCH_MODE            MATCH_MODE_TDM
```

на:

```pawn
#define DEFAULT_MATCH_MODE            MATCH_MODE_DM
```

Затем пересоберите игровой режим и обновите `.amx` вместе с исходником.

## Файлы

- `gamemodes/dm_tdm.pwn` — исходный код режима;
- `gamemodes/dm_tdm.amx` — скомпилированный режим для прямого скачивания;
- `config.json` — конфигурация open.mp, указывающая на `dm_tdm.amx`;
- `.github/workflows/build-openmp.yml` — автоматическая сборка на GitHub.

## Артефакт автоматической сборки

Сборка запускается при push в `main` или ветки `arena/**`, при pull request в `main`, а также вручную. После успешной сборки откройте репозиторий на GitHub → **Actions** → выберите запуск **Build open.mp DM/TDM** → скачайте артефакт `openmp-dm-tdm-<commit>`. В ZIP находятся оба файла: `dm_tdm.pwn` и `dm_tdm.amx`.

## Локальная компиляция

Нужны Pawn-компилятор open.mp и стандартные include-файлы open.mp. Укажите путь к `pawncc` и каталог, в котором лежит `open.mp.inc`:

```bash
PAWNCC=/path/to/pawncc \
OMP_INCLUDE_DIR=/path/to/open.mp/qawno/include \
./scripts/build.sh
```

Скрипт создаст `gamemodes/dm_tdm.amx` рядом с исходником.

## Запуск сервера

1. Установите серверные файлы open.mp отдельно — исполняемый файл сервера в этот репозиторий не включён.
2. Скопируйте `config.json`, каталог `gamemodes/` с обоими файлами и остальные необходимые папки в каталог сервера.
3. Запустите сервер `omp-server` (Linux) или `omp-server.exe` (Windows).

Перед публикацией игрового сервера настройте его имя, порт, объявление в masterlist и сетевые параметры. RCON в шаблонной конфигурации выключен.
