# open.mp DM/TDM

Игровой режим для **open.mp** на Pawn. По умолчанию работает Team Deathmatch: команды RED/BLUE, авто-баланс, счёт, лимит 30 убийств и раунды по 15 минут. В исходнике можно выбрать FFA Deathmatch через `DEFAULT_MATCH_MODE`.

Режим использует только встроенный API open.mp — сторонние плагины и компоненты не нужны. Координаты арены и набор оружия пока тестовые; системные сообщения в первой сборке на английском.

## Готовые файлы

- `gamemodes/dm_tdm.pwn` — исходник;
- `gamemodes/dm_tdm.amx` — скомпилированный игровой режим;
- `config.json` — конфигурация сервера, RCON выключен.

## Полный серверный пакет

GitHub Actions собирает два минимальных серверных пакета из официального open.mp runtime `v1.5.8.3079`:

- Windows: `openmp-dm-tdm-server-windows-<commit>`;
- Linux: `openmp-dm-tdm-server-linux-<commit>`.

Откройте репозиторий на GitHub → **Actions** → успешный запуск **Build and package open.mp DM/TDM** → скачайте артефакт под нужную ОС. Внутри уже находятся сервер open.mp, его стандартные runtime-файлы, `config.json`, наш `.pwn` и `.amx`, а также скрипт запуска. Примеры игровых режимов и неиспользуемые плагины/компоненты удаляются; дополнительные плагины для нашего режима не нужны. Артефакты Actions хранятся 30 дней.

Запуск распакованного пакета:

- Windows: `start.bat`;
- Linux: `bash ./start.sh`.

Сервер слушает UDP-порт `7777`. Для подключения извне его нужно разрешить в firewall/на хостинге.

## Сборка игрового режима отдельно

Автоматическая сборка также публикует артефакт с парой `.pwn` + `.amx`. Для локальной компиляции нужны `pawncc` open.mp и include-файлы с `open.mp.inc`:

```bash
PAWNCC=/path/to/pawncc \
OMP_INCLUDE_DIR=/path/to/open.mp/qawno/include \
./scripts/build.sh
```
